Tag reference

  

    
Tags, elements and attributes


A tag is a marker in angle brackets. <p> is a start tag; </p> is an end tag (note the forward slash).


An element is a complete unit: start tag + content + end tag, such as <p>Fresh bread</p>. Empty (void) elements such as br, hr, img and input have no content and no end tag.


An attribute gives extra information about an element. It is a name="value" pair written inside the start tag, separated from other attributes by spaces.


<a href="fees.html" target="_blank">School fees</a>

tag name ....... a
attributes ..... href="fees.html"  target="_blank"
content ........ School fees
end tag ........ </a>


Nest correctly: the last element opened is the first one closed. <p><b>Hot</b></p> is right; <p><b>Hot</p></b> is wrong.

    

    
Page skeleton


<!DOCTYPE html>
<html lang="en">
<head>
  <title>Shown on the browser tab</title>
</head>
<body>
  Everything visitors see goes here.
</body>
</html>


<!DOCTYPE html> declares an HTML5 document (it is a declaration, not an element). html is the root element that contains everything. head holds information about the page, such as the title. body holds the visible content.

    

    
Headings, paragraphs, line breaks


<h1>Main heading (use once)</h1>
<h2>Section heading</h2>
<h3>Sub-section heading</h3>  ... down to h6
<p>A paragraph of text.</p>
<p>Line one<br>Line two</p>
<hr>   a horizontal rule (dividing line)


Browsers ignore extra spaces and the line breaks you type in the code. A new paragraph needs <p>; a new line inside a paragraph needs <br>.

Lists


<ul>            unordered: bullets, order does not matter
  <li>Water</li>
  <li>Torch</li>
</ul>

<ol type="A">   ordered: numbers or letters, order matters
  <li>Secure shutters</li>
  <li>Charge phones</li>
</ol>


The type attribute of ol can be "1", "A", "a", "I" or "i"; start sets the first number. A description list uses dl, dt (term) and dd (description).

    

    
Links


<a href="https://www.example.com">Absolute: a full URL</a>
<a href="contact.html">Relative: a file on the same site</a>
<a href="pages/menu.html">Relative, in a folder</a>
<a href="#prices">Bookmark: jump to id="prices"</a>
<a href="mailto:info@example.com">Email link</a>
<a href="https://www.example.com" target="_blank">Opens in a new tab</a>

<h2 id="prices">Prices</h2>
<a href="index.html"><img src="logo.png" alt="Home"></a>   image link


Relative links keep working when the whole site folder moves to a new web server. Link text should describe the destination, not say "click here".

    

    
Images


<img src="reef.jpg" alt="Coral and fish at Buccoo Reef" width="400" height="260">




AttributePurpose


srcThe file name, path or URL of the image (required)


altAlternative text: shown if the image fails to load and read aloud by screen readers


width, heightDisplay size in pixels: a plain number, no "px"


titleTooltip shown when the pointer hovers




File names must match exactly, including capitals: many web servers treat Reef.JPG and reef.jpg as different files.

    

    
Tables


<table border="1">
  <caption>Ferry times</caption>
  <tr>
    <th>Day</th> <th>Depart</th> <th>Fare</th>
  </tr>
  <tr>
    <td>Monday</td> <td>09:00</td> <td>$15</td>
  </tr>
  <tr>
    <td colspan="3">No sailings on public holidays</td>
  </tr>
</table>


tr = table row, th = header cell (bold and centred), td = data cell. Tables are built row by row; columns appear because each row has the same number of cells. colspan stretches a cell across columns; rowspan stretches it down rows.

    

    
Forms


<form action="register.php" method="post">
  <label for="fname">First name</label>
  <input type="text" id="fname" name="fname">

  <label for="em">Email</label>
  <input type="email" id="em" name="email">

  <label for="town">Town</label>
  <select id="town" name="town">
    <option>Castries</option>
    <option>Gros Islet</option>
  </select>

  <button type="submit">Register</button>
</form>


action is where the data is sent; method="post" sends it inside the HTTP request (used for private or larger data), get adds it to the URL. A label's for must match the control's id. Every control needs a name, or its data is not sent. Other inputs: password, radio, checkbox, number, date, and <textarea> for longer text.

    

    
Inline style and a little CSS


<h1 style="color: darkblue; text-align: center;">Notice</h1>

<style>            goes inside the head
  body { font-family: Arial, sans-serif; }
  h1   { color: darkgreen; }
</style>


A declaration is property: value; with a colon in the middle and a semicolon at the end. Style uses American spelling: color and center. Writing colour or centre is silently ignored.


Useful properties: color, background-color, font-family, font-size, text-align, font-weight, font-style, width, border.

    

    
How the Web works


    

  • The Internet is the global network of networks. The World Wide Web is a service on it: interconnected hypertext documents (web pages) joined by hyperlinks.
    • 

  • A web browser (the client software) requests pages, interprets the HTML and displays the result. A web server stores pages and sends them when they are requested. This is the client–server model.
    • 

  • HTTP (HyperText Transfer Protocol) is the set of rules for requesting and sending pages. HTTPS is HTTP with encryption, shown by the padlock.
    • 

  • Status codes: 200 OK, 404 Not Found, 500 server error.
    • 

  • DNS (Domain Name System) translates a domain name into the server's IP address.
    • 



https://www.sunsetcove.jm/rooms/deluxe.html
protocol ....... https://
domain name .... www.sunsetcove.jm   (TLD: .jm, Jamaica)
path ........... /rooms/
file name ...... deluxe.html

    

    
Paper 02 tips


    

  • Write the skeleton first (html, head with title, body), then fill it. Examiners award marks for the complete structure.
    • 

  • Close every element you open, in the right order, and put attributes inside start tags with the value in quotation marks.
    • 

  • Read the question for exact words: "unordered list" means ul; "inline styling" means the style attribute, not a separate style block.
    • 

  • When asked to "identify" URL parts, label each part and state its role.
    • 

  • There is no browser in the exam room. Practise typing pages from memory, then check them here.
