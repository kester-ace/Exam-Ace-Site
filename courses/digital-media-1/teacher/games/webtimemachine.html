    Evolution of the Web: revision sheet

    CAPE Digital Media Unit 1 · Module 1 · Evolution of digital media · Name: ____________________

    1. From analogue to digital

    Analogue media store information as continuous physical signals (vinyl grooves, magnetic tape, film, print). Copies lose quality; distribution is physical or broadcast. Digital media store information as binary numbers: perfect copies, easy editing, compression and instant global sharing.

    Timeline: 1970s analogue print, radio, TV, vinyl, cassette · 1980s PCs, CD, cable TV and satellite dishes on the islands · 1990s World Wide Web, dial-up, Web 1.0 · 2000s broadband, social media, smartphones, Web 2.0 · 2010s 4G, apps, streaming, cloud, data analytics, Web 3.0 · 2020s 5G, generative AI, IoT, Web 4.0 ideas · 2030+ Web 5.0 (emerging).

    3. Enabling technologies

    • Broadband: always-on, fast connections made video, streaming and cloud normal (made Web 2.0 possible).
    • Mobile devices: a studio and broadcaster in every pocket; the Caribbean went "mobile first".
    • Data analytics: evidence-based decisions and personalised feeds (drives Web 3.0).
    • AI in content creation: generative media, automated editing, captions and translation; raises originality and deepfake concerns.

    4. Accessibility and connectivity

    Enablers
    • Internet access: fibre, 4G/5G, community Wi-Fi
    • Lower device cost and subsidies
    • Digital literacy classes
    • Assistive technology: captions, alt text, screen readers
    • Resilience: buried fibre, redundant cables, satellite back-up
    Barriers
    • Cost of devices and data
    • Geography: small islands, rural areas, offshore cays, few submarine cables
    • Disability: inaccessible sites and media
    • Infrastructure: power cuts, hurricane damage
    • Also: language, education, age, socio-economic status

    5. Exam reminders

    • User-role chain: reader → participant → co-creator → partner.
    • Call Web 4.0 "emerging" and Web 5.0 "partly speculative".
    • Pair each barrier with the enabler that answers it, and give a Caribbean example.
