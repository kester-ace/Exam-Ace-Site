From the Virtual Scavenger Hunt (student version) · Digital Media live class activity

You have 20 minutes: ready, set, go!

How to play

  1. Go to the Virtual Scavenger Hunt Folder (link in Teams chat).
  2. For each item below, either upload a photo or screenshot and save it in the subfolder labelled with your name.
  3. Name each file like this: Item01_Typography.jpg
  4. Use a different photo for every item: no repeats!
  5. When time is up, stop uploading. You might be picked to share one find with the class!
