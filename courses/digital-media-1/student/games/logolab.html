Tints, shades and tones of the base colour

Tint = add white. Shade = add black. Tone = add grey. Select a cell to copy its hex code.

RYB, RGB or HSL? This wheel is an RGB/HSL screen wheel, the one used in apps like Photoshop, Illustrator and Canva. On a painter's RYB wheel the complement of red is green, but on a screen wheel it is cyan. Use RGB/hex for screens and CMYK for print.
