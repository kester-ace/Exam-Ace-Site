Cheat sheet

  

    
Page skeleton


<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Page name | Site name</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  ...everything visitors see...
</body>
</html>


The head holds information about the page. The body holds the content. The doctype keeps the browser in standards mode.

    

    
Text, headings and lists


<h1>One main heading per page</h1>
<h2>Section heading</h2>
<h3>Sub-section</h3>
<p>A paragraph with <strong>important</strong> and <em>stressed</em> words.</p>

<ul>            <!-- order does not matter -->
  <li>Free Wi-Fi</li>
</ul>
<ol>            <!-- order matters -->
  <li>Leave the airport</li>
</ol>


Never skip heading levels to get smaller text. Change size with CSS.

    

    
Links


<!-- internal (relative) -->
<a href="rooms.html">Rooms and rates</a>

<!-- external, new tab, safe -->
<a href="https://www.bvitourism.com"
   target="_blank" rel="noopener noreferrer">Tourist Board (opens in a new tab)</a>

<!-- anchor on the same page -->
<a href="#directions">Jump to directions</a>
<h2 id="directions">Getting here</h2>

<!-- email -->
<a href="mailto:stay@guavaberrygrove.vg">Email us</a>

    

    
Images, video, audio, maps


<img src="images/hero.jpg" alt="Sunset over Sea Cows Bay"
     width="1200" height="500">

<video src="tour.mp4" controls width="640"></video>
<audio src="welcome.mp3" controls></audio>

<iframe src="https://www.youtube.com/embed/VIDEO_ID"
        title="Video tour" width="560" height="315" allowfullscreen></iframe>

<iframe src="https://maps.google.com/maps?q=Sea%20Cows%20Bay&output=embed"
        title="Map of Sea Cows Bay" width="600" height="400" loading="lazy"></iframe>


Use JPEG for photos, PNG for logos and screenshots that need sharp edges or transparency, SVG for icons, MP4 (H.264) for video and MP3 for audio.

CSS rules and selectors


selector {
  property: value;
}

p { }            /* element */
.card { }        /* class: many elements, class="card" */
#top { }         /* id: one element, id="top" */
nav a { }        /* descendant: links inside nav */
a:hover { }      /* pseudo-class: when the mouse is over */
h1, h2 { }       /* group */


CSS uses American spelling: color, center, gray or grey. Writing colour silently fails.


Specificity: id beats class, class beats element. If equal, the rule written last wins.

Box model


From outside to inside: margin (space outside), border, padding (space inside the border), content.


.card {
  margin: 1rem 0;            /* top/bottom 1rem, left/right 0 */
  border: 2px solid #e0a526;
  padding: 1rem 1.25rem;
}
* { box-sizing: border-box; } /* width includes padding and border */


Shorthand order is clockwise: top, right, bottom, left.

    

    
Flexbox


nav ul {
  display: flex;              /* children sit in a row */
  gap: 1rem;                  /* space between items */
  justify-content: center;    /* main axis: start, center, space-between */
  align-items: center;        /* cross axis */
  flex-wrap: wrap;            /* allow a new line */
  list-style: none;
}

    

    
Units, resolution and responsive design




UnitMeaningUse for


pxCSS pixel, fixedborders, small details


remtimes the root font size (usually 16px)font sizes, spacing; respects the user's settings


emtimes the parent's font sizepadding on buttons


%share of the parentwidths, max-width: 100%


vw / vh1% of viewport width / heightfull-screen sections


pt, cm, mmphysical unitsprint stylesheets only




Screen vs print: screens care about pixel dimensions (a hero 1200 to 1600 px wide is plenty). Print needs about 300 dpi: a 10 cm wide print needs roughly 1,180 pixels. A "72 dpi" setting does not change how big an image looks on screen; the pixel count does.


img, iframe { max-width: 100%; }
img { height: auto; }

@media (max-width: 600px) {
  nav ul { flex-direction: column; }
}

    

    
Accessibility (WCAG) and usability


    

  • Text contrast at least 4.5:1; large text (24px, or 18.66px bold) at least 3:1.
    • 

  • Every meaningful image has alt text that describes it. Decorative images use alt="".
    • 

  • Every form field has a <label for="id">.
    • 

  • Link text makes sense on its own: "View room rates", not "click here".
    • 

  • Set lang on <html>; use headings in order; every iframe has a title.
    • 

  • Do not rely on colour alone; keep a visible focus style for keyboard users.
    •
