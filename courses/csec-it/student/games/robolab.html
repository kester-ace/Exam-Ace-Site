Robot facts

  • Grid squares are 50 cm. Bolt is about 26 cm wide.
  • Heading: 0 = north (up), 90 = east, 180 = south, 270 = west.
  • x grows to the right, y grows upwards from the bottom-left corner.
  • Speed 50% ≈ 40 cm per second.
  • The distance sensor measures from Bolt's front bumper.
  • Two line sensors sit just in front, 6 cm left and right of centre.

Errors (SO 8.3)

  • Syntax error: breaks the language rules (missing colon, bracket). Found before running.
  • Run-time error: crashes while running (e.g. divide by zero).
  • Logic error: runs fine but does the wrong thing. Find it with Step, trace tables and dry runs.

How to play

1 · Build

Drag blocks from the palette into the workspace and snap them under when ▶ Run clicked. C-shaped blocks (repeat, if) wrap other blocks. Round reporters and pointy conditions drop into matching slots. Click white numbers to edit them.

On a phone or tablet: press and drag. Long-press a block for Duplicate/Delete.

2 · Run & test

▶ Run plays your program in the arena. ⏭ Step runs one block at a time and highlights it — perfect for finding logic errors. ↺ Reset puts Bolt back (and gives a new layout on 🎲 missions). The slider changes the speed.

3 · Check & earn stars

Goals tick off live. ★ 1 star for completing the goals, plus a star for each bonus (fewer blocks, no bumps, faster…). 🎲 missions are also tested on unseen layouts, so use sensors!

4 · See the code

The Code tab translates your blocks into CXC pseudocode, a flowchart, Python, JavaScript, Pascal, Visual Basic, C and Java. Hover a line to light up its block. Level 3 missions use 🐍 Python text mode.

5 · Keep evidence

⋯ → Export my work downloads a report with your algorithm, flowchart, code and test results — great for your SBA notes. You can also export/import programs as .json files.

Accessibility

☰ List mode lets you build programs with the keyboard or a screen reader: choose a block, choose where, press Add. Sound is off by default (🔇 button). Animations respect reduced-motion settings.

Robo Lab is a learning simulator.
